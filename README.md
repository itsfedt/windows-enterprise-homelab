# Windows Enterprise Homelab

A hands-on Windows enterprise infrastructure project built around the fictional company Asteria Digital GmbH. The project simulates the design and administration of a small corparate Windows envrionment using Active Domain Services, DNS, DHCP, Group Policy, Windows Files Services and PowerShell.

A later phase will extend the environment with Microsoft Entra ID and Microsoft Intune. 

## Project Goals
- Build a virtual Windows enterprise network
- Deploy Active Directory Domain Services
- Configure DNS and DHCP
- Manage users, computers, Organizational Units and security groups
- Join Windows clients to the domain
- Deploy workstation policies using Group Policy
- Implement department-based file access
- Automate adminisrtative tasks using PowerShell
- Practice security hardening and troubleshooting
- Explore Microsoft Entra ID and Intune

## Fictional Organization
